# riccidevloper.com

Static site for Ricci A.'s apps, served by GitHub Pages.

- `/` home
- `/worthfolio/` app page
- `/worthfolio/privacy/` Privacy Policy (App Store Connect Privacy Policy URL)
- `/worthfolio/support/` Support (App Store Connect Support URL)
- `/worthfolio/terms/` Terms of Use

No build step: plain HTML and one stylesheet in `assets/`.
